## 三、前端 UI 特效

### 3.1 Antigravity 粒子光标效果

- 全局背景层，`position: fixed`，`pointer-events: none`
- 基于 Three.js + @react-three/fiber 的 InstancedMesh 粒子系统
- 使用全局 `window.addEventListener('mousemove')` 追踪鼠标（Canvas 不接收事件）
- 鼠标悬停侧边栏时粒子淡出（React Context 控制 opacity 过渡）
- 配色 `#cbc4e8`，opacity 0.3，autoAnimate 自动运动

### 3.2 ShapeBlur 形状模糊效果

- 首页四张卡片，hover 时显现 ShapeBlur 背景
- 使用自定义 shader（RoundRect SDF），形状边界对齐卡片边缘
- `shapeSize=2.1` 对齐卡片边界，`u_aspect` 按宽高比拉伸 X 轴
- 每张卡片使用不同的 variation（0-3），鼠标移动时形状产生模糊变形
- 颜色 `#2563eb`（primary-600），opacity 0.7

## 五、Phase 2：Demo 生成 + ReAct Agent ✅

### 5.1 AI 适配层


| 文件                              | 说明                                                              |
| --------------------------------- | ----------------------------------------------------------------- |
| `ai/AiProviderAdapter.java`       | 统一适配器接口（streamCompletion + streamWithTools）              |
| `ai/AiProviderFactory.java`       | 按 provider 名称路由到对应适配器                                  |
| `ai/OpenAiCompatibleAdapter.java` | OpenAI 兼容格式实现（支持 DeepSeek/小米/自定义）                  |
| `ai/AiFunction.java`              | 工具定义（name + description + parametersJson）                   |
| `ai/AiChunk.java`                 | 输出块（TEXT / THOUGHT / TOOL_CALL / TOOL_RESULT / DONE / ERROR） |
| `ai/AiChunkType.java`             | 输出块类型枚举                                                    |
| `ai/ToolHandler.java`             | 工具执行函数接口                                                  |

### 5.2 ReAct Agent 引擎

- **全响应式实现**：使用 `Sinks.Many` + `subscribe()` 递归调用，兼容 Netty 事件循环
- **多轮推理**：最多 3 轮，AI 自主决定是否调用工具
- **工具执行**：`search_links`（搜索知识库）+ `get_framework_info`（获取框架信息）
- **实时推送**：每个 chunk 通过 SSE 即时推送到前端

### 5.3 Demo 服务

- **流式生成**：`DemoController` → `DemoService` → `ReActAgent` → `OpenAiCompatibleAdapter`
- **前置检查**：HTTP 400 拦截未登录/未配置 AI 的请求
- **自动保存**：流式完成后在 `doOnComplete` 中提取代码块和关键词存入 `demos` 表
- **历史记录**：已登录用户可查看/删除历史 Demo

### 5.4 前端 Demo 页面

- **SSE 流式渲染**：useSSE Hook 解析 thought / tool_call / text / done / error 事件
- **ReAct 可视化**：思考过程（蓝色卡片）、工具调用（琥珀色卡片）
- **代码输出**：Markdown 风格渲染，代码块带语言标签 + `max-h-80` 可滚动
- **错误通知**：集成 useNotify 全局弹窗

### 5.5 数据库


| 表      | 迁移文件 | 说明                                                                |
| ------- | -------- | ------------------------------------------------------------------- |
| `demos` | V5       | Demo 记录（user_id, title, prompt, code_content, language, tags[]） |

## 七、修复的问题


| 问题                                            | 修复                                                    |
| ----------------------------------------------- | ------------------------------------------------------- |
| React 19`useRef()` 不传参报错                   | `useRef<T                                               |
| `import path from 'path'` ESM 不可用            | Vite alias 改用`/src`                                   |
| `keepExisting` 属性不存在                       | 改为`keepExistingData`                                  |
| `writable.size` 不存在                          | 先`getFile()` 再取 `file.size`                          |
| `idb` 包导入失败                                | 去掉依赖，改用原生 IndexedDB API                        |
| `LocalActivityStorage` 是 class                 | 改为纯函数导出                                          |
| `@types/wicg-file-system-access` 缺失           | 手动安装类型定义                                        |
| Antigravity Canvas 遮挡侧边栏点击               | `pointer-events: none` + 全局 mousemove                 |
| ShapeBlur 白色不可见                            | 添加`u_color` uniform，默认蓝色                         |
| ShapeBlur 形状未对齐卡片边界                    | `shapeSize=2.1` + `u_aspect` 宽高比拉伸                 |
| `IdType.ASSIGN_UUID` 与 `java.util.UUID` 不兼容 | 改为`IdType.INPUT` + 手动生成 UUID                      |
| MyBatis Plus 缺少 UUID TypeHandler              | 自定义`UuidTypeHandler` + 全局注册                      |
| PostgreSQL text[] 无 TypeHandler                | 自定义`StringArrayTypeHandler`                          |
| `IdType.ASSIGN_UUID` 生成 String 而非 UUID      | 改为`IdType.INPUT` + `UUID.randomUUID()`                |
| MyBatis Plus 无 UUID TypeHandler                | 自定义`UuidTypeHandler` + 全局注册                      |
| AES key 长度 46 字节不合法                      | 使用 SHA-256 从 jwt.secret 派生 32 字节密钥             |
| Flyway 校验和不匹配（V4 种子数据修改后）        | `clean-on-validation-error: true`                       |
| `blockLast()` 阻塞 Netty 线程                   | 重写 ReActAgent 为`Sinks.Many` + `subscribe()` 递归模式 |
| 小米 API 不支持`role: "tool"`                   | 改用`assistant` + `user` 角色传递工具结果               |
| `reasoning_content` 被当作回复输出              | 只输出`content` 字段，跳过 `reasoning_content`          |
| useSSE 吞掉错误不抛出                           | catch 块中加`throw error`                               |
| SSE 流中错误事件无法返回                        | 改为 HTTP 400 前置检查 + GlobalExceptionHandler         |
| demos 表始终为空                                | 在`doOnComplete` 回调中调用 `saveDemoSync()` 保存       |
| AI 连接测试只检查字段非空                       | 改为真正发送 API 请求验证连通性                         |
| 连接测试首个 chunk 内容为空                     | 添加`.filter(chunk -> !chunk.isEmpty())`                |
